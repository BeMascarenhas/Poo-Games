# Sobre o jogo
### Este jogo foi inspirado no "Space Invaders" porém há modificações que o tornam unico.
### O jogo foi desenvolvido em C++ e utilizamos a biblioteca Raylib.
### Para ver os slides da apresentação clique [aqui](https://github.com/user-attachments/files/16660897/ApresentacaoPOO.pdf)

# Como Jogar
### Faça uma cópia do repositório para sua máquina local.
### Instale a biblioteca Raylib.
### Após isso, clique no arquivo game.exe e aproveite o jogo.
